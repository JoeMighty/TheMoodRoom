The Mood Room - Documentation

Technical architecture details and step-by-step setup guides.

1. Technical Architecture

"The Mood Room" operates as a completely serverless static application. This keeps running costs strictly at zero while delivering real-time capabilities.

  • Frontend: Pure HTML5, CSS3, and JavaScript (ES Modules). No heavy frameworks, bundlers, or Node.js compilers are required.
  • Database & Sync: Cloud Firestore (Firebase). Enables real-time document listeners so participant thoughts animate onto the display screen instantly.
  • Content Moderation: Dual-layer validation (Local regex word boundaries followed by a keyless REST API filter query to PurgoMalum).
  • Hosting: GitHub Pages (Static hosting).

2. Firebase Setup Guide

Follow these steps to connect your Firebase project (themoodroom-24902) to the codebase:

Step A: Register the Web App

  1. Open the Firebase Console.
  2. Select your project TheMoodRoom.
  3. Under the project title overview, click the Web icon (</>).
  4. Enter the App Nickname: The Mood Room Web App.
  5. Leave "Also set up Firebase Hosting" unchecked and click Register App.
  6. Copy the apiKey and appId values from the generated configuration block.

Step B: Update Configuration File

Open js/firebase-config.js in your code editor and update the API Key and App ID:

const firebaseConfig = {
  apiKey: "PASTE_YOUR_API_KEY_HERE",
  authDomain: "themoodroom-24902.firebaseapp.com",
  projectId: "themoodroom-24902",
  storageBucket: "themoodroom-24902.appspot.com",
  messagingSenderId: "1033227730513",
  appId: "PASTE_YOUR_APP_ID_HERE"
};

Step C: Enable Cloud Firestore

  1. In the Firebase Console sidebar, click Build -> Firestore Database.
  2. Click the Create database button.
  3. Select Standard (billing/plan) and click Next.
  4. Choose your database location (select a location closest to your physical installation site) and click Next.
  5. Select Start in test mode and click Create.

Step D: Configure Database Rules

  1. Navigate to the Rules tab at the top of your Firestore Database dashboard.
  2. Paste the following configuration (copied from firestore.rules) into the editor:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /exhibitThoughts/{document} {
      allow read, write: if true;
    }
  }
}
  1. Click Publish.

3. Deployment (GitHub Pages)

  1. Ensure all changes are committed in Git: 
    git add .
git commit -m "Initialize installation code"
git push
  2. Navigate to your repository page on GitHub (https://github.com/JoeMighty/TheMoodRoom).
  3. Click the Settings tab.
  4. Select Pages in the left sidebar under "Code and automation".
  5. Under Build and deployment, choose "Deploy from a branch", set branch to main, and choose folder / (root).
  6. Click Save. The application will be live in 1–2 minutes.
